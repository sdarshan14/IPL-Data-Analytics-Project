# IPL Data Analytics Project

## Project Overview

This project analyzes IPL (Indian Premier League) cricket data using Python and data analytics techniques.

The project performs:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Sports Analytics
- Data Visualization
- Insights Generation

---

# Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

# Features

Team Performance Analysis  
Top Run Scorers Analysis  
Most Sixes Analysis  
Toss Decision Analysis  
Matches Per Season Trends  
Visualization Dashboards  

---

# Dataset

Dataset used:
- matches.csv
- deliveries.csv

Source:
Kaggle IPL Dataset

# Key Insights

- Mumbai Indians and Chennai Super Kings are among the most successful teams.
- Top batsmen dominate IPL scoring charts consistently.
- Teams often prefer fielding after winning the toss.
- IPL popularity and match count increased across seasons.
